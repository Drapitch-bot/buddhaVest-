## איך לצלם בפועל

**מטלפון אנדרואיד אמיתי (הכי פשוט ומומלץ):**
צלם רגיל (Power + Volume Down). כמעט כל מסך של טלפון מודרני נותן 1080×2400 או
יותר — כלומר **גבוה מ-9:16**, וזה נופל על הכלל "הצלע הארוכה לא יותר מפי 2
מהקצרה"? 2400/1080 = 2.22 — **חורג**. לכן צריך לחתוך.

חיתוך ל-1080×1920 בדיוק, בלי לעוות (נשמר מרכז התמונה):
```
pip install Pillow
```
```python
from PIL import Image
import glob, os

os.makedirs("out", exist_ok=True)
for p in sorted(glob.glob("*.png")) + sorted(glob.glob("*.jpg")):
    im = Image.open(p).convert("RGB")          # RGB = בלי אלפא, כפי שנדרש
    w, h = im.size
    # התאמה ל-9:16 בחיתוך מרכזי — לעולם לא מתיחה
    target = 9 / 16
    if w / h > target:
        nw = int(h * target); im = im.crop(((w - nw) // 2, 0, (w + nw) // 2, h))
    else:
        nh = int(w / target); im = im.crop((0, (h - nh) // 2, w, (h + nh) // 2))
    im.resize((1080, 1920), Image.LANCZOS).save(
        os.path.join("out", os.path.splitext(os.path.basename(p))[0] + ".png"))
    print("ok", p)
```
> חיתוך מרכזי חותך מלמעלה ומלמטה. אם המידע החשוב בקצה המסך — צלם קצת "רחב"
> יותר, או חתוך ידנית ל-1080×1920.

**מאמולטור (Android Studio):** בחר מכשיר עם מסך 1080×1920 (Pixel 4 / Nexus 5X),
ואז הצילום כבר במידות הנכונות בלי חיתוך.
